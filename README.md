# FunCatDelivery Mobile App

FunCatDelivery is an Android food delivery mobile application developed using Java and Android Studio. The app allows users to browse food items, add them to a cart, place orders, and track their delivery status.

## Features
- Browse food menu
- Add items to cart
- View cart and checkout
- Order confirmation
- Order tracking

## Technologies Used
- Java
- Android Studio
- XML Layout

## Purpose
This project was developed as a university project to demonstrate Android mobile application development and basic food ordering system functionality.
